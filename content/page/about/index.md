这里记录我在这些方向上的学习过程：**算法竞赛**、**C 与底层**、**Python 与 AI**、**Rust 与区块链**，以及**高等数学、线性代数、概率论、数理统计、密码学、离散数学**。偶尔也写点随笔。

## 写作约定

- 正文用中文；**专业术语保留英文原词**，不做硬译
  - 保留英文的：`borrow checker`、`move semantics`、`lazy propagation`
  - 用中文的：特征值（eigenvalue）、正定矩阵、极大似然估计
- 中英文之间加空格
- 全站口径统一：同一个概念只使用一种写法
- 代码注释用中文，标识符与关键字保持英文

## 关于这个站

用 [Hugo](https://gohugo.io/) 构建，主题是 [Stack](https://github.com/CaiJimmy/hugo-theme-stack)，
在原有主题上补了三件事：

- **代码分组**：同一算法的多语言实现可以并排或切换对照
- **公式与图表本地化**：KaTeX 与 Mermaid 全部自托管，不依赖外部 CDN
- **中文友好的字体栈**：不加载 Google Fonts，优先使用系统内的中文字形

内容以 Markdown 存放在 Git 仓库里，站点是构建产物。
