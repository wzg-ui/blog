## 开场

八篇 Python 写完，下一个问题立刻冒出来：接着写什么。

脑子里存着一堆「以后要写」——数据、算法、竞赛、考研。它们没有先后，也没有期限，最后大概会变成一句「有空再说」。

写下来会好一点。至少在不知道该干嘛的时候，往回翻一眼，就知道下一件是什么。

这篇会一直挂在最上面，想到什么就改什么。

## 已经发出去的

Python 语法那八篇是齐的：装环境、基础语法、容器、函数、字符串与正则、类、文件与异常、装饰器与生成器。现在打包成了站里第一个专栏，从第一篇顺读到最后，是一条完整的线。

数学那边起了一篇《高等数学（一）》，照 CMC 非数学 A 类的考纲写的，还没发。

另外站里有一篇投稿，讲一道 x→−∞ 的根号极限。

## 接着写代码

语法这东西，看懂和会写是两回事。光看不动手，过两周就忘了。

所以下一篇是动手的：把前面那些零散的东西拼成一个能跑的程序，容器、函数、类、文件都用上。具体做什么还没定，可能是个成绩统计，可能是个命令行小工具，写到一半觉得没意思，换掉也不算什么损失。

不追求做完，先追求跑起来。

## 数据那几篇

Python 真正被大量用到的地方是数据。

numpy 管数组和运算，pandas 管表格，matplotlib 画图，sklearn 拿来跑几个模型。这四个过完，再拿一份真实的数据从头做一遍：读进来、洗一遍、算、画出来、写一句结论。

顺序不能反。没有数组那一层的概念，pandas 里那些操作就只能靠背。

## 数模

再往后是数模。

国赛 C 题那种：给一张表、一段背景，几天之内把模型建出来、结果算出来、图做出来、论文写出来。它和数据那几篇是一条路，但多了建模和写作——前面各篇学的东西，到这里第一次全部用上。

这一篇估计很长，可能要拆成两三次。

## 欠的账

写的路上留了几句没兑现的话：

- 并查集、线段树、平衡树。容器篇提过，但用 Python 写这三样性价比不高，当时就没往下写。等复习算法的时候补。
- Git。装环境那篇说「这个也可以写一写」，一直没写。
- Linux。同上。
- 计算机组成。容器篇开头提了图灵和冯诺依曼，那应该是另一条线的事。
- Anaconda。入门篇说「以后再写」，数据那几篇开始之前正合适。

欠着不难受，硬凑一篇才难受。

## 代码之外

站里不只放代码。今年还压着几件事，花的时间和写文章差不多：

- CMC 非数学 A 类。数学那篇就是照这个准备的，赛前过一遍，赛后把真题里卡住我的地方补回来。
- 考研。这件事打算边走边记，不写成经验帖那种东西。
- 英语。一直要补，具体怎么补还没定下来。
- 专业课。内容不比 Python 少，可能会挑几门有意思的单独写。
- 还有一封信，用英语写给一个女生。这封不一定放上来，先记在这儿。

## 收个尾

写在这儿的，大部分会变。顺序会变，有的会消失，有的会多出来。

真到那天，我回来改这一篇就是了。反正它就挂在最上面。
