## 索引与切片

<!--
C++ 没有的东西，是 Python 最有特色的一块。

要点：
- [start:stop] 左闭右开
- 负索引从后往前数
- 切片返回的是**新对象**，不是视图
- 三种切片写法：正着、反着、跳步

对照：C++ 里 vector 的区间操作要么写循环，要么用 span / 迭代器区间。
Python 直接内建，而且比 C++ 简洁得多。

查：tutorial/introduction.html 的 序列部分
⚠️ 这里很容易写出「切片是引用、修改会改到原列表」的错结论，
   记得实测一下再写。
-->

## 控制流

<!--
- if / elif / else，和 C++ 一样是自上而下第一个成立的分支
- for 的迭代对象范围比 C++ 广得多（任何可迭代对象）
- range(n) 是惰性的，不真的产生一个列表
- while 和 C++ 基本一致
- break / continue 和 C++ 一致
- **循环的 else 子句**：C++ 没有，要写清楚它是「没被 break 才执行」

查：tutorial/controlflow.html（4. 更多控制流工具）

## 列表推导式

<!--
Python 风格的核心，也是最容易写出「为了用而用」的地方。

要点：
- 基本形式 [f(x) for x in xs]
- 带条件 [f(x) for x in xs if cond]
- 嵌套对应 C++ 的多层循环
- 什么时候**不该**用：逻辑一复杂，推导式就比 for 难读

对照：C++ 里同样的事情要么写 lambda + 标准算法，要么写显式循环。

⚠️ 这里会用到「函数」的概念（f(x)、lambda），但正式的定义在下一篇。
   提一句「下一篇会细讲」就行，不要在这里展开。

查：tutorial/controlflow.html 最后一节（列表推导式）
-->
