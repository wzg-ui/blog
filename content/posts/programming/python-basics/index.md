## 变量：名字绑到对象上

### 什么？你要谈对象了？

看到这句话的你，是不是很开心呀？恭喜你，终于要和 Python 谈恋爱了！不过先别急，你得先认识一下**变量**，以及它背后的“对象”。只要你开始写 Python，就几乎绕不开它们的存在。

当然，这里说的对象和你想找的对象可不是一回事哈。

对于变量的基本概念，这里就不赘述了。比起重复基础知识，我更想聊聊 Python 和 C++ 在变量使用上的一些区别。

首先是常量。在 C++ 中，我们可以使用 `const` 声明常量：

```cpp
const double PI = 3.1415;
```

但是 Python 没有像 C++ 的 `const` 那样，能够通过通用的变量声明机制禁止重新赋值。通常，我们会用全大写的名字表示不希望被修改的值：

```python
PI = 3.1415
```

不过，这只是约定俗成的命名规范，并不会阻止你修改它。Python 选择了把这个决定交给程序员——当然，也把相应的责任交给了程序员。

### 名字与对象：Python 和 C++ 的区别

除了常量，另一个值得聊聊的问题就是内存地址（可以理解成一个房间）。这也是 Python 与 C++ 在变量机制上的一大区别。

我们经常会听到这样一句话：Python 中一切皆对象。

在 Python 中，变量名可以理解为绑定到对象上的一个名字。对象有自己的类型、值和身份，我们可以通过 `id()` 查看对象的身份标识。

```python
a = 10
print(id(a))  # 查看对象的身份标识

b = a
print(id(b))  # 通常与 a 的结果相同
```

执行 `b = a` 后，`b` 也绑定到了与 `a` 相同的对象。因此，两次输出的身份标识相同。

注意，这里不是把 `a` 中的值复制一份，再交给 `b`，而是让 `b` 也绑定到这个对象上。

在 CPython 中，`id()` 通常对应对象的内存地址，但 Python 语言规范并不要求所有实现都这样做。我们现阶段只需要知道：`id()` 可以帮助我们辨认对象身份。

再来看看 C++：

```cpp
int a = 10;
int* p = &a;

cout << &a << endl;
cout << p << endl;
```

这里，`a` 是一个 `int` 变量，`&a` 取得它的地址，而指针 `p` 保存了这个地址。两次输出的地址相同。

这和 Python 的变量绑定机制并不完全相同。C++ 中的变量通常具有明确的类型，赋值行为也会受到类型和值类别等规则的影响；Python 则通过名字与对象之间的绑定来管理变量。

当然，C++ 也有引用、指针和动态分配的对象，不能简单地认为 C++ 变量都在栈上，而 Python 对象都在堆上。两种语言的内存管理机制，还有不少值得深入研究的地方。

### `==` 和 `is`：下面该上点强度了

```python
a = 10
b = 10

print(a == b)
print(a is b)
```

答案会是什么呢？

在常见的 Python 实现中，两个结果通常都是 `True`。是的，问题开始变得有趣起来了！

想必 `==` 还是比较好判断的，它比较的是值是否相等。那么问题来了，`is` 是干什么的呢？

它判断的是**对象身份**。身份怎么判断？简单来说，就是看两个变量绑定的究竟是不是同一个对象。

上面这种情况，多个变量可能指向同一个对象。在 CPython 中，`-5` 到 `256` 之间的整数通常会被缓存并复用，所以这里的 `a is b` 通常为 `True`。

当然，这还只是开胃菜。如果把难度再加大一点呢？

```python
a = 1010
b = 1010

print(a == b)
print(a is b)
```

这次的答案超出了 `256`，是不是就该不一样了？

等等，答案可能还是 `True`！

这次就不一定是小整数缓存的功劳了。在某些情况下，CPython 会复用同一代码块中的常量对象，因此两个变量可能仍然绑定到同一个对象。

不过要注意，这个结果并没有保证。不同的 Python 实现、执行环境或代码组织方式，都可能影响对象是否被复用。所以，**不能用 `256` 作为判断 `is` 结果的分界线**哈。

这一次，强度再次加大！

```python
a = 1010
b = int("1010")

print(a == b)
print(a is b)
```

这次又会怎么样呢？

`a == b` 的结果是 `True`，因为两个对象的数值相同。

至于 `a is b`，在常见的 CPython 环境中，这种写法通常会得到 `False`。原因是 `a` 绑定到整数常量对象，而 `int("1010")` 则通过运行时转换得到整数对象，通常不会与前者是同一个对象。

但是，这里同样不能把 `False` 当成所有 Python 实现都必须遵守的保证。我们真正应该记住的，不是某个数字到底会不会被复用，而是 `is` 比较的是对象身份，而不是数值。

所以，最后总结一下：

- `==`：比较两个对象的值是否相等。
- `is`：比较两个变量是否绑定到同一个对象。

平时比较数字，用 `==` 就好；判断对象身份时，再考虑 `is`。千万别为了省两个字符，把代码写出意想不到的惊喜来！

这貌似很好理解吧，最基本的是赋值，然后是算术、关系、逻辑。通常可以把它们的优先级概括为：算术运算高于比较运算，比较运算高于 `not`，而 `not` 高于 `and`，`and` 高于 `or`。

这会等于几呢？好像小学没教过负数的余数啊。这边呢，我们只要记住 Python 中取模的一个特点：结果通常与除数同号。

## 输入与输出

### 输入语句

`input()` 很容易看懂，但下面问题来了：

```python
a = input()
b = int(input())
c, d = eval(input())
```

他们的 `type` 分别是什么呢？

直接说答案吧，第一个是**字符串类型**，第二个是转换成了**整数**。至于第三个，它会把输入的字符串当作 Python 表达式求值，再把结果解包给 `c` 和 `d`。例如输入 `1, 2`，就会得到两个整数。

既然讲到 `eval()` 了，那我觉得有必要深入讲一下原理吧。毕竟同时转换多个数据，里面的原理像一个黑盒。

而实际上，`eval()` 确实容易让人觉得像黑盒，因为它把字符串当作 Python 表达式求值。一句话概括：

`eval(expression, globals=None, locals=None)` 把字符串当作 Python 表达式求值，并返回结果。

```python
eval("1 + 2")          # 3
eval("3 * 4")          # 12

x = 10
eval("x + 5")          # 15
eval("len('hello')")   # 5
```

注意，它只能处理表达式（有返回值的东西），不能处理赋值语句或条件语句：

```python
eval("a = 1")          # SyntaxError
eval("if True: pass")  # SyntaxError
```

要执行语句得用 `exec()`：

```python
exec("a = 1")
print(a)  # 1
```

黑盒感来自哪里？

`eval()` 的“黑盒”在于：字符串里的名字（变量、函数）从哪来？答案由 `globals` 和 `locals` 决定。

```python
eval("x + y")  # 如果当前作用域没有 x、y，就会引发 NameError
```

你可以手动提供命名空间：

```python
eval("x + y", {"x": 1, "y": 2})  # 3
```

规则大致是：

- 不传 `globals`：使用当前环境的全局命名空间；在函数内部调用时，具体的局部变量查找行为也需要注意。
- 传了 `globals` 但不传 `locals`：`locals` 默认使用 `globals`。
- 两个都传：先查 `locals`，再查 `globals`，最后查内置命名空间。

`eval()` 确实不是很容易被驾驭，所以我的原则是：**永远不要对不可信输入使用 `eval()`**。

这里再提一点，上面写到了 `exec()`，这里简单写一下吧。`exec()` 和 `eval()` 是兄弟，区别就一句话：

`eval()` 求一个表达式的值并返回；`exec()` 执行一段代码语句，通常返回 `None`，它不会像 `eval()` 一样返回表达式的计算结果。

实际编程中，如果只是想输入几个数字，通常没有必要使用 `eval()`，例如：

```python
a, b = map(int, input().split())
```

这样就可以从一行输入中读取两个整数了。

对于这一章，我觉得没有什么可写的，很简单的语法应用，什么？你要上点强度，很简单，直接去做大模拟，你问PIEMM做吗，好吧，PIEMM被这玩意折磨的也是够了，PIEMM是一个喜欢脑力挑战的人，当算法竞赛真的面对一个百行的大模拟题目时，那真的是灾难，毕竟你可能永远都不知道你会漏写哪个条件，而这些条件的主要语句就是下面所讲的：

关于语法，这里只想写一下相对C++特殊的地方，正常的C++几乎不写循环和选择并列
但在python中，
会发现有这样的写法：
Python 靠缩进划分代码块，而 C++ 靠花括号 {}。 不过，else 的作用不是告诉 Python 循环在哪里结束，而是明确表示循环正常结束后要执行的代码。
例如：
```py
n = int(input())
for i in range(2, n):    
    if n % i == 0:
          print("不是素数")        
          break
else:    
    print("是素数")
```

这里的 else 与 for 对齐，因此它属于 for，而不是内部的 if。
如果去掉 else，直接把 print("是素数") 放在循环后面，那么即使循环中触发了 break，循环结束后也会执行这条语句，导致结果错误。
C++ 中一般会这样写：
```cpp
bool flag = true;

for (int i = 2; i < n; i++) {
    if (n % i == 0) {
        flag = false;
        break;
    }
}

if (flag) cout << "是素数";
else cout << "不是素数";
```
所以，Python 的 for...else 本质上是提供了一种更简洁的表达方式，可以省掉额外的标志变量。缩进负责划分代码块，**else 负责表达循环未被 break 打断时的逻辑**。

## PIEMM的试炼

看到这个名字，你不会已经吓到了吧，几个有意思的题目（算法竞赛里入门难度，掌握了他们也算是步入最低门槛啦）

### 1. 最大公约数和最小公倍数

输入两个正整数，求他俩的最大公约数和最小公倍数。

```py
a = int(input("请输入a："))
b = int(input("请输入b："))

if a < b:
    a, b = b, a
s = a * b
while a % b != 0:
    a, b = b, a % b
else:
    print("最大公约数为：%d" % b)
    print("最小公倍数为：%d" % (s//b))
```
比起去解释代码语法，我还是想主要写一写这个数学逻辑，这是一个入门级别的数论问题，
你所看到的while循环是**欧几里得算法**，感兴趣的可以去看**OIWIKI**，看到的`s//b`也有相应的公式。
先定义gcd(a,b)是最大公约数，lcm(a,b)是最小公倍数

这是包装的函数形式：
```py
def gcd(a, b):
    while b != 0:
        a, b = b, a % b
    return a
```
再换个写法：
```py
def gcd(a,b):
  if b != 0:
    return gcd(b,a%b)
  else:
    return a
```
先做个注释：`mod` 是取模运算，表示取余数。`|`是整除的意思。

**证明：**

设 \(a=bk+c\)，则 \(c=a\bmod b\)。

假设 \(d\mid a\)，\(d\mid b\)，也就是说，\(d\) 是 \(a,b\) 的一个公约数。

因为 \(c=a-bk\)，所以

\[
\frac{c}{d}=\frac{a}{d}-\frac{b}{d}k
\]

问题来了，看到这个式子有什么想法吗？

因为 \(d\mid a\)，\(d\mid b\)，所以 \(\frac{a}{d}\) 和 \(\frac{b}{d}\) 都是整数，因此 \(\frac{c}{d}\) 也是整数，即 \(d\mid c\)。

所以，\(d\mid(a\bmod b)\)，也就是说，\(d\) 仍然是 \(b\) 和 \(a\bmod b\) 的公约数。

反过来也需要证明一下。已知 \(d\mid b\)，\(d\mid(a\bmod b)\)。

我们知道

\[
a\bmod b=a-bk
\]

因此

\[
\frac{a}{d}
=\frac{a\bmod b}{d}+\frac{b}{d}k
\]

右边是整数，所以 \(\frac{a}{d}\) 也是整数，即 \(d\mid a\)。

因此，\(a,b\) 的公约数与 \(b,a\bmod b\) 的公约数完全相同。

既然两组数的公约数集合相同，那么它们的最大公约数也相同。

所以得到：

\[
\boxed{\gcd(a,b)=\gcd(b,a\bmod b)}
\]

对于最小公倍数：

设 \(a,b\) 的质因数分解分别为

\[
a=p_1^{k_{a_1}}p_2^{k_{a_2}}\cdots p_s^{k_{a_s}}
\]

\[
b=p_1^{k_{b_1}}p_2^{k_{b_2}}\cdots p_s^{k_{b_s}}
\]

其中，\(p_1,p_2,\ldots,p_s\) 表示涉及的所有质数，对于没有出现在某个数的质因数分解中的质数，其对应指数记为 \(0\)。

我们发现，对于 \(a\) 和 \(b\)，二者的最大公约数等于

\[
\gcd(a,b)=
p_1^{\min(k_{a_1},k_{b_1})}
p_2^{\min(k_{a_2},k_{b_2})}
\cdots
p_s^{\min(k_{a_s},k_{b_s})}
\]

而最小公倍数等于

\[
\operatorname{lcm}(a,b)=
p_1^{\max(k_{a_1},k_{b_1})}
p_2^{\max(k_{a_2},k_{b_2})}
\cdots
p_s^{\max(k_{a_s},k_{b_s})}
\]

由于对于任意两个非负整数 \(x,y\)，都有

\[
\min(x,y)+\max(x,y)=x+y
\]

因此

\[
\gcd(a,b)\times\operatorname{lcm}(a,b)=a\times b
\]

最终得到结论：

\[
\boxed{\operatorname{lcm}(a,b)=\frac{a\times b}{\gcd(a,b)}}
\]

所以，要求两个正整数的最小公倍数，先求出它们的最大公约数即可。

### 2. 求 200 以内最大的 10 个素数的和

用嵌套循环判断素数：外层从 200 往下遍历（从大的开始，才能先凑够 10 个），
内层试除到 `i` 的**平方根范围**（这里实际除多了），一旦发现因子就 `break`，跳出内层循环。一个都找不到，就说明是素数（经典的试除法筛素数）

```py
s = 0
k = 0
for i in range(200, 1, -1):
    for j in range(2, i):
        if i % j == 0:
            break
    else:
        s = s + i
        k = k + 1
    if k >= 10:
        break

print("200 以内最大的 10 个素数的和为：", s)
```


### 3. 冒泡排序

把较大的数不断往后"冒"。内层两两比较交换，把本轮最大的元素推到未排序区的末尾。

```py
lst = [15, 20, 7, 85, 34, 67, 80, 10, 13, 52]
n = len(lst)

for i in range(n - 1):
    for j in range(n - i - 1):
        if lst[j] > lst[j + 1]:
            lst[j], lst[j + 1] = lst[j + 1], lst[j]

print("排序结果：", lst)
```

两个 `range` 的边界是这题的全部难点：

- 外层 `range(n - 1)`：排 9 轮。不是排 n 轮，因为排完前 9 个，最后一个自然就位了
- 内层 `range(n - i - 1)`：**每轮少比一个**，因为末尾的元素已经归位，不能再动它


运行结果：`[7, 10, 13, 15, 20, 34, 52, 67, 80, 85]`


### 4. 选择排序

每一轮从未排序区里挑出最大（或最小）的，放到未排序区的末尾。轮数比冒泡少，所以更快。

```py
lst = [15, 20, 7, 85, 34, 67, 80, 10, 13, 52]
n = len(lst)

for i in range(n - 1):
    max_i = i
    for j in range(i + 1, n):
        if lst[j] > lst[max_i]:
            max_i = j
    if max_i != i:
        lst[i], lst[max_i] = lst[max_i], lst[i]

print("排序结果：", lst)
```

运行结果：`[85, 80, 67, 52, 34, 20, 15, 13, 10, 7]`（降序）


### 5. 计算交错级数

$$s = 1 - \frac{1}{4} + \frac{1}{7} - \frac{1}{10} + \frac{1}{13} - \frac{1}{16} + \cdots$$

分母每次加 3，符号正负交替。循环次数事先不知道，所以用 `while`。

```py
i, f, s = 1, 1.0, 0.0
while abs(1.0 / i) > 1e-5:
    s = s + f * 1.0 / i
    i = i + 3
    f = -f
print("s=%.2f" % (s))
```

三个变量各管一件事：

| 变量 | 作用 |
|---|---|
| `i` | 当前分母，循环体里 `i += 3` |
| `f` | 当前符号，`f = -f` 每轮翻转（`1.0` / `-1.0`） |
| `s` | 累加结果 |

终止条件用 `abs()` 包一下，因为级数是**正负交替**的，直接写 `1.0 / i > 1e-5` 在分母为负时会提前退出。

运行结果：`s=0.84`



### 五道题串起来看

抛开题目本身，这五道题其实把上一节的东西全用了一遍：

- **分支**：第 1 题的 `if a < b` 交换、第 2/4 题的 `if k >= 10: break`
- **循环**：`while` 管次数未知的（第 1、5 题），`for` 管次数已知的（第 2、3、4 题）
- **`for...else` / `while...else`**：第 1、2 题都在用，是这批题里最值钱的一个语法
- **多重赋值**：第 1 题的 `a, b = b, a % b`、第 3 题的 `lst[j], lst[j+1] = lst[j+1], lst[j]`
- **整除与浮点**：第 1 题的 `//`、第 5 题的 `/`，一字之差结果类型就不同
- **`break` 的位置**：第 2 题的 `if k >= 10: break` 放在内层 `for...else` **外面**，
  缩进差一级，语义完全不同
