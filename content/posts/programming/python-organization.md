## 类

<!--
**只写最小必要部分**，不要展开面向对象思想、不要讲设计模式。
目标是「能看懂别人写的 class，能自己写一个简单的小类」。

要点：
- class 关键字、self
- __init__
- 属性 vs 方法
- 继承（只提语法）
- 为什么 Python 的方法第一个参数都要写 self
- **属性是在运行时绑定的** —— 这一点和 C++ 差别最大，值得展开

对照：C++ 的 class / struct。
C++ 里成员函数和成员变量在类定义时就确定了；
Python 里方法和属性都是挂在类上的对象，运行时才组装。

查：tutorial/classes.html（9. 类）
