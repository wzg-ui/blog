# 本地音乐（`source = "local"` 时用这个目录）

把音频丢进来，重新构建，歌单会**自动生成** —— 不用手写任何列表。
适合想放自己的歌、又不想被第三方接口卡住的场合（比如有 QQ 音乐 / 网易云会员，
把歌下下来转成 mp3 放这儿，就能 100% 播出来）。

## 三步用起来

1. 打开 `config/_default/params.toml`，把 `[music]` 的 `source` 改成 `"local"`
2. 音频按下面的命名规则放进这个目录
3. 重新构建（或本地预览刷新），点右上角唱片即可

## 命名规则

```
歌手 - 歌名.mp3      ← 减号两边各留一个空格，别用别的横杠
歌手 - 歌名.jpg      ← 可选，同名图片会被当作唱片封面（flac 就写成 歌手 - 歌名.flac）
```

例子：

| 放进去的文件 | 播放器里显示 |
| --- | --- |
| `周杰伦 - 晴天.mp3` + `周杰伦 - 晴天.jpg` | 晴天 / 周杰伦，带封面 |
| `陈奕迅 - 十年.mp3` | 十年 / 陈奕迅，封面用默认黑胶盘面 |
| `demo.mp3` | demo /（歌手空）—— 不按规则也能用，整名当歌名 |

## 支持的格式

- **音频**：`.mp3` `.flac` `.m4a` `.ogg` `.wav` —— 按扩展名识别，flac 主流浏览器都能播
- **封面**：`.jpg` `.png` `.webp` —— 与音频同名即可

想增减，改 `layouts/_partials/footer/custom.html` 顶部的 `$audioExts` / `$coverExts`
两个列表，改完重新构建。

## 两个注意事项

- ⚠️ **这些文件会进 git 仓库**（`assets/` 不在 `.gitignore` 里）。320kbps 的 mp3
  一首约 8–10 MB，攒多了仓库会明显变胖，建议控制在 20 首以内
- ⚠️ 把自己下载的商业音乐放到公开网站上分发**有版权风险**，这个得自己权衡

想换回在线音源：把 `source` 改回 `"api"` 即可，这个目录留着不影响。
